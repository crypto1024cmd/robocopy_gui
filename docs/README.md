## 这是什么

**RoboCopy 批量搬运**是一个 Windows 桌面工具：它自己**不实现复制算法**，而是图形化地组织、
调度并观察系统自带的 `robocopy.exe`（`C:\Windows\System32\Robocopy.exe`），
用 `/MT` 多线程完成「源目录 → 目标目录」的高速批量搬运。

技术栈为 Rust + Tauri（前端 Vite + React + TypeScript），界面是浅色卡片式布局：
顶栏总进度、中部任务卡片列表、右栏运行统计与设置、底部深色日志控制台。

## 核心能力

| 能力 | 说明 |
|---|---|
| 多任务管理 | 一次配置多条「源 → 目标」任务，逐条编辑/预览/删除 |
| 批量调度 | 点「开始全部」按加入顺序依次执行，可设并行任务数 1..8 |
| 实时进度 | 复制中显示百分比、已复制/总字节、瞬时速度、ETA、当前文件 |
| 完整日志 | 每次执行写一份完整日志到工作目录 `logs/`，界面按任务节流展示 |
| 复制后校验 | 三级：不校验 / 大小+时间戳 / 哈希（MD5、SHA1、SHA256） |
| 命令行透明 | 任何任务都能「预览」出即将执行的 robocopy 命令，可复制到剪贴板 |
| 安全护栏 | 路径关系自检（自我递归/覆盖直接阻止）、`/MIR` 二次确认、`/L` 试运行不写盘 |
| 单文件源 | 源既可以是整个目录，也可以是**单个文件** |

## 适用与不适用

**适合**：移动硬盘/大容量盘/NAS 之间的整目录或单文件批量搬运与备份；
需要在界面上看进度、事后查日志、做复制后校验的场景。

**不适合**（当前版本无此能力，不要期待）：

- 定时/计划任务、断点续跑的自动恢复（本工具是一次性批量搬运）；
- 配置持久化：任务与参数只存在内存中，**关闭程序后任务列表清空**（详见 [常见问题](./faq.md)）；
- 跨平台运行（依赖 Windows 的 `robocopy.exe` 与 WebView2）。

## 运行环境

- Windows 10 / 11，需具备 WebView2 运行时（Win10/11 一般预装）；
- 系统自带 `robocopy.exe`（缺失时点「开始全部」会报错，见 FAQ）；
- 仅使用打包好的 exe 时**不需要** Node.js；构建源码时才需要 Rust 1.75+ / Node.js 18+。

## 五步上手

1. 点「＋ 新增任务」（或按 `Ctrl+N`）打开任务编辑器；
2. 填「源路径」（目录或单个文件）与「目标目录」，等待状态行显示绿色「校验通过 ✓」；
3. 选择复制模式（普通 `/E` 或镜像 `/MIR`）、多线程数、复制后校验级别；
4. 点「保存任务」，回到主界面；
5. 点「▶ 开始全部」（或按 `F5`），在任务卡片上看进度、在底部「运行日志」看实时输出，
   任务结束后可点卡片上的「日志」查看完整记录。

## 术语表

| 术语 | 含义 |
|---|---|
| 源路径 | 要搬运的起点，可以是整个目录，也可以是单个文件 |
| 目标目录 | 搬运的落地目录；**目录源**会在此目录下新建与源同名的子目录 |
| 实际落盘位置 | 目录源的真实写入点：`<目标目录>\<源目录名>`；单文件源与盘符根源直接落在目标目录 |
| 有效目标根 | 引擎内部的同一概念，命令行、进度统计、复制后校验统一按它计算 |
| 镜像 `/MIR` | 让目标与源完全一致，会**删除**目标端多余的文件/目录（界面有二次确认） |
| 试运行 `/L` | 只列出将要复制的文件，不写入任何数据，也不做复制后校验 |
| 终态 | 已完成 / 已停止 / 失败；只有终态任务能被删除或重跑 |
| 校验 | 复制结束后的比对过程，三档：不校验 / 大小+时间戳 / 哈希 |
