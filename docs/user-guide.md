# 用户指南

面向实际操作：界面每一处是什么、每个按钮做了什么、每个选项的默认值与取值范围。

---

## 1. 界面总览

窗口标题「RoboCopy 批量搬运」，默认 1200×800、可缩放、启动时居中，最小 1000×640。
界面自上而下分为四块：

```
┌───────────────────────────────────────────────────────────────┐
│ 顶栏：标题 · 总进度 · [开始全部][停止全部][新增任务][设置][日志目录] │  高 62px（深色）
├───────────────────────────────────┬───────────────────────────┤
│ 任务卡片列表（按源路径字母序）      │ 右栏（宽 340px）           │
│                                   │ 本次运行 / 运行设置 /      │
│                                   │ 新任务默认参数             │
├───────────────────────────────────┴───────────────────────────┤
│ 底部日志控制台「运行日志」（默认展开，高 260px，深色）           │
└───────────────────────────────────────────────────────────────┘
```

**窄窗口的自适应行为**（界面按窗口宽度自动取舍，属预期行为）：

| 窗口宽度 | 表现 |
|---|---|
| ≥ 1120px | 顶栏显示「⚙ 设置」按钮 |
| < 1120px | 「⚙ 设置」按钮隐藏，随之无法从界面「清空已完成任务」（日志目录仍可用顶栏「🗀 日志目录」或 `Ctrl+L`） |
| ≥ 1040px | 显示右栏（本次运行 / 运行设置 / 新任务默认参数） |
| < 1040px | 隐藏整个右栏（运行设置、并行任务数、进度刷新、默认参数都看不到） |

窗口最小宽度为 1000px，因此把窗口拖到最窄时会隐藏右栏与设置按钮。

**任务列表排序**：按「源路径」字符串字母序展示（不是添加顺序）。引擎的**执行顺序**仍按
任务加入顺序先进先出，两者不同属预期。

## 2. 任务状态与颜色

| 状态 | 徽标文案 | 颜色 | 含义 |
|---|---|---|---|
| pending | 待执行 | 灰 | 已保存、尚未被调度 |
| scanning | 扫描中 | 橙 | 正在扫描源清单、统计总大小 |
| running | 复制中 | 蓝 | robocopy 正在复制 |
| verifying | 校验中 | 青 | 复制结束，正在做复制后校验 |
| done | 已完成 | 绿 | 正常结束 |
| stopped | 已停止 | 橙 | 被手动停止，或校验被中断 |
| failed | 失败 | 红 | robocopy 退出码 ≥ 8，或校验未通过 |

「待执行」不等于「正在运行」：运行状态由引擎的 `running` 事件表达，
因此刚添加完任务时「开始全部」仍然可用。

|---|---|---|

| 总进度 | 进度条 + `已复制 / 总计（百分比）` + 速度 + `进行中 非终态数/任务总数` | 全部任务累计口径 |

| 日志目录 | `🗀 日志目录` | 用资源管理器打开工作目录下的 `logs/`；快捷键 `Ctrl+L` |

## 4. 任务卡片

每张卡片从上到下六行：

| 行 | 内容 |
|---|---|
| 1 | `编辑`（**运行中禁用**，悬浮提示「运行中不可编辑」）、`预览`、任务名（空则「未命名任务」）、右侧状态徽标 |
| 2 | `源路径 → 目标目录`；路径过长时折叠显示为「首两段…末两段」，鼠标悬浮可见完整路径 |
| 3 | 失败显示红色 `⚠ <错误信息>`；已完成显示退出码说明；已停止显示「已停止」；运行中显示阶段文本（如「正在比对目标目录…」「正在校验 120/540」）；待执行显示参数摘要（如 `普通 /E · /MT:16 · 校验 大小+时间戳`） |
| 4 | 进度条 + 百分比 + `已复制 / 总字节` |
| 5 | 速度 + `ETA <剩余时间>` + `当前文件：<文件名>` |
| 6 | 统计 `共 N 文件 · 已存在 X · 校验 通过/已校验 · 耗时 Y`，右侧操作按钮 |

第 6 行各按钮的可用条件：

| 按钮 | 可用条件 | 行为 |
|---|---|---|
| `停止` | 引擎运行中且该任务非终态 | 二次确认后立即终止该任务的 robocopy 进程 |
| `重跑` | 引擎未运行且任务为终态 | 重置为「待执行」并清零进度，提示「任务「X」已重置为待执行」 |
| `日志` | 该任务已有日志文件（`log_path` 非空） | 打开日志查看器（尾部约 32KB） |
| `删除` | 引擎运行中禁用 | 二次确认后从列表移除（只影响列表，不动已复制的文件） |

**进度与「已存在」的口径**：引擎在复制开始前先扫描一次目标端，
「已存在 X」表示目标端本来就已是最新、无需重写的字节数；
进度条按「目标端实际已完整写入的字节数 / 源总字节数」计算，
且只有文件大小与源完全一致才计入，写了一半的文件不会被算成已完成。
若源总大小未知（扫描未完成），则非终态任务显示 0%，终态且无错误显示 100%。

**空列表提示**：📂「还没有复制任务 / 新建一个「源目录 → 目标目录」任务，然后点击「开始全部」开始高速搬运」+ `＋ 新建任务` 按钮。

## 5. 新建 / 编辑任务

标题统一为「编辑复制任务」，宽 760px。

### 5.1 字段与按钮

| 区域 | 说明 |
|---|---|
| 源路径 | 文本框 + `浏览目录…` + `浏览文件…`。占位提示：`D:\照片\2024  或  D:\照片\视频.mp4` |
| 任务名称 | 可选；留空时自动使用源名称（目录源的末段名，如 `…\照片\2024\` → `2024`） |
| 目标目录 | 文本框 + `浏览目录…` + `盘符…` 下拉（选择盘符会把当前源的末段名拼到该盘符下，便于快速改盘） |

`浏览目录…` 选择后会规范化成反斜杠并以 `\` 结尾；`浏览文件…` 填入完整文件路径（不加尾部分隔符）。

### 5.2 实时校验（输入后约 0.8 秒自动触发）

| 结果 | 界面文案 |
|---|---|
| 通过 | 绿色 `校验通过 ✓`（源为单个文件时追加「（源为单个文件）」） |
| 空 | 红字 `源路径与目标目录都必须填写` |
| 相同 | 红字 `源路径与目标目录不能相同` |
| 目标在源内 | 红字 `目标目录位于源目录内部，会导致自我递归复制，已阻止` |
| 源在目标内 | 红字 `源位于目标目录内部，可能造成数据覆盖，已阻止` |
| 源不存在 | 红字 `源路径不存在（既不是文件夹也不是文件）` |

校验不通过时点「保存任务」不会保存，而是弹出错误提示：
`任务保存失败：<上面的原因文案>`。

校验通过且源是目录时，界面会额外提示**实际落盘位置**：
「目录将整体复制到：`<目标目录>\<源目录名>`」。

### 5.3 源大小估算与目标盘空间

- 输入源路径后自动估算（约 0.8 秒防抖）：
  目录源显示 `源目录：N 个文件 / M 个目录，合计 X`；单文件源显示 `源文件，合计 X`；
  未填时显示「填写源路径后自动估算大小」，估算中显示「正在估算源大小…」。
- `校验目标盘空间` 按钮（目标目录为空时禁用）：对比源总大小与目标盘可用空间，
  结果为绿色「足够」或红色「目标盘可用空间不足：需要 X，可用仅 Y（总容量 Z）」；
  无法读取目标盘信息时提示「无法读取目标盘可用空间，请自行确认」。

### 5.4 复制参数与命令行预览

- 复制参数区即「[复制参数详解](#6-复制参数详解)」中的面板；
- **命令行预览**随参数变化实时刷新（约 0.3 秒防抖），深色代码块显示即将执行的 robocopy 命令。

### 5.5 镜像 `/MIR` 的二次确认

新建任务时，若勾选了镜像 `/MIR` 且源是目录，点「保存任务」会弹出红色警告：

> ⚠ 已选择镜像模式 /MIR
> 镜像 /MIR 会把目标端「源里没有、目标里有」的文件与目录全部删除，让目标与源完全一致。
> 请确认：目标目录中不存在需要保留的文件！

确认按钮为「确认使用镜像」，取消则返回编辑器。编辑**已有**任务时不再重复弹窗。

### 5.6 源为单个文件时的特殊行为

- 「复制模式」的第一段文案由 `普通 /E` 变为 `单文件`，`镜像 /MIR` 置灰不可选，
  并提示「源为单个文件，已禁用镜像 /MIR」；
- 若此前已勾选镜像，会自动取消；
- 保存时该任务的镜像被强制关闭（**不影响**右栏的「新任务默认参数」）；
- 命令行变成 `robocopy <源文件所在目录> <目标目录> <文件名> …`，文件直接落进目标目录、文件名不变。

### 5.7 编辑器底部提示原文

> 提示：源可以是整个目录，也可以是单个文件。目录会整体复制到目标目录下并新建同名子目录；
> 单个文件则直接复制进目标目录、文件名不变。本工具直接调用系统 robocopy 完成；
> 勾选「镜像 /MIR」会删除目标端多余文件，请谨慎使用。

## 6. 复制参数详解

参数面板同时出现在**任务编辑器**与右栏**「新任务默认参数」**中，两处控件完全一致。

| 选项 | 界面文案 | 默认值 | 取值范围 | 说明 |
|---|---|---|---|---|
| 复制模式 | `普通 /E` \| `镜像 /MIR` | 普通 `/E` | 二选一 | `/MIR` 会删除目标端多余文件，需二次确认；单文件源禁用 |
| 多线程 | `多线程` + 数字框 + `8 / 16 / 32 / 64` 预设 | 16 | 1..128 | 传给 `/MT:n`，是提速的主要手段 |
| 复制后校验 | `不校验` \| `大小+时间戳` \| `哈希校验` | 大小+时间戳 | 三选一 | 详见 [校验](#9-复制后校验) |
| 哈希算法 | `MD5（最快）` / `SHA1（较安全）` / `SHA256（最安全）` | MD5 | 三选一 | 仅当校验级别为「哈希校验」时可选，否则置灰 |
| 试运行 `/L` | `试运行 /L（只列出将要复制的文件，不写入任何数据）` | 关 | 开/关 | 位于折叠的「高级选项」内 |
| 断点重启 `/Z` | `断点重启 /Z（网络不稳建议开启，速度明显下降）` | 关 | 开/关 | 位于折叠的「高级选项」内 |

「高级选项（试运行 / 断点重启）▼」默认收起，点击展开/收起。

面板底部的动态提示：

- 不校验 → `不进行复制后校验，速度最快`
- 大小+时间戳 → `复制结束后对比每个文件的大小和修改时间（2 秒容差），开销极低`
- 哈希校验 → `复制结束后对每个文件计算 <算法> 并与源端逐字节比对，最严格但最耗时`

以及一行参数摘要，例如 `普通 /E · /MT:16 · 校验 大小+时间戳`。

> **界面未提供入口的参数**：`/R`（失败重试次数，取值范围 0..20）与
> `/W`（重试等待秒数，0..120）在数据模型中存在并会写进命令行，默认值为 `/R:1 /W:1`，
> 但当前版本没有对应的界面控件。

### 命令行固定参数

除上表选项外，命令行还会固定带上以下参数（可在「预览」中看到）：

| 参数 | 作用 |
|---|---|
| `/COPY:DAT` | 复制数据、属性、时间戳 |
| `/XJ` | 排除联接点/符号链接，避免意外递归复制 |
| `/BYTES` | 统计表输出精确字节数 |
| `/NP` | 输出去掉逐文件百分比 |
| `/NDL` | 输出去掉目录清单 |

**路径规则**：路径中的 `/` 会规范化为 `\`；含空格时自动加引号；超长路径自动加 `\\?\` 前缀
（UNC 路径为 `\\?\UNC\`），因此长路径（>260 字符）与网络共享同样可用。

## 7. 右栏（窗口 ≥ 1040px 可见）

| 卡片 | 内容 |
|---|---|
| 本次运行 | `共 N 个任务（已完成 x · 失败 y）`、`已复制 X`、`总计 Y` |
| 运行设置 | `并行任务数` 下拉 1..8（默认 1）；`进度刷新` 下拉 `0.5 秒 / 1 秒 / 2 秒 / 3 秒`（默认 1 秒） |
| 新任务默认参数 | 与任务编辑器同款的参数面板，改动后作为**后续新建任务**的初始值 |

运行设置下方的固定提示：

> 轮询间隔越小进度越实时，但会占用少量磁盘 IO；并行任务数对机械硬盘建议不超过 2。

`进度刷新` 会立即作用于正在运行的任务（引擎内部对过小的间隔有 0.2 秒下限保护）。

## 8. 运行、停止与清理

| 操作 | 入口 | 二次确认文案 |
|---|---|---|
| 开始全部 | 顶栏 `▶ 开始全部` / `F5` | 无 |
| 停止单个 | 卡片 `停止` | 标题 `停止任务「X」？`；正文 `运行中的 robocopy 进程将被立即终止，目标目录中可能留下不完整文件。`；确认键 `停止任务` |
| 停止全部 | 顶栏 `■ 停止全部` | 标题 `停止所有任务？`；正文同上；确认键 `停止` |
| 删除任务 | 卡片 `删除` | 标题 `删除任务「X」？`；正文 `该操作只把它从列表移除，已复制的文件不受影响。`；确认键 `删除` |
| 清空已完成 | 「⚙ 设置」→ `清空已完成任务` → `清空` | 标题 `清空所有已完成任务？`；正文 `只把已完成的任务从列表移除，日志与已复制的文件不受影响。`；确认键 `清空` |
| 重跑 | 卡片 `重跑` | 无（重置为待执行） |

调度规则：

- 「开始全部」把**待执行**任务按加入顺序交给调度器，并行数量由右栏决定；
- 终态任务不会被重复执行，需要先「重跑」；
- 删除任务在引擎中只对终态生效（PENDING/运行中不可删除）；
- 一轮任务全部结束时弹出提示「所有任务已执行完毕」，「停止全部」按钮随之恢复置灰。

任务到达终态时的顶部提示（右上角轻提示）：

- 完成 → `任务「X」完成`
- 失败 → `任务「X」失败：<错误信息或退出码说明>`
- 停止 → `任务「X」已停止`

**退出程序**：关闭窗口会终止所有运行中的 robocopy 子进程并等待调度线程退出，
因此退出前请确认没有重要任务在跑；被强停的任务会在目标端留下不完整文件。

## 9. 复制后校验

| 级别 | 界面文案 | 行为 |
|---|---|---|
| 关 | 不校验 | 跳过校验，进度视为 100%，阶段文本为「复制完成（未校验）」 |
| 快 | 大小+时间戳 | 逐文件比对大小与修改时间；时间戳带 **2 秒容差**（适配 FAT/exFAT 的 2 秒精度） |
| 严 | 哈希校验 | 逐文件计算 MD5 / SHA1 / SHA256 并比对内容；按 1MB 分块流式读取，以 4 个线程并发（上限 8） |

- 校验中卡片显示「正在校验（<级别>）…」与实时进度「正在校验 120/540」；
- 全部一致 → 状态「已完成」，阶段文本 `完成并通过校验（N 个文件，耗时 X）`；
- 存在差异 → 状态**失败**，错误信息 `校验未通过：x/N 个文件不一致`；
- 大小不一致的文件直接判失败，不再浪费时间做哈希；
- 试运行 `/L` 不进入校验阶段（只统计将要复制的范围）。

**差异明细的可见范围（重要）**：界面在卡片上只显示「校验 通过数/已校验数」的汇总，
不提供差异列表弹窗；失败明细写在任务的日志文件里，且最多记录前 10 条。
引擎内部的差异记录上限为 500 条，超出部分只计数。

## 10. 日志

### 10.1 底部「运行日志」控制台

| 元素 | 说明 |
|---|---|
| 任务筛选下拉 | `全部任务` + 各任务显示名（默认「全部任务」） |
| `自动滚动` | 默认勾选，勾选时始终滚到最新一行 |
| 行数统计 | `<N> 行`，被裁剪时追加 `（已裁剪 M 行）` |
| `收起 ▼ / 展开 ▲` | 折叠或展开日志区（面板固定高 260px） |
| 空态 | `暂无日志输出` |

性能护栏（卡顿时可据此解释）：界面只在内存里保留最近 2000 行日志，
超限时按 400 行步长丢弃最旧的行并累计「已裁剪」计数；面板本身最多渲染最后 800 行；
日志以 60ms 批量刷新上屏；单条日志超过 400 字符会被截断并加 `…`。
以 `»` 开头的行是引擎自身的过程提示，会以蓝色高亮显示。

### 10.2 完整日志文件

- 位置：程序**工作目录**下的 `logs/`（开发/`-Release` 方式启动时即项目根目录）；
  顶栏「🗀 日志目录」或 `Ctrl+L` 可直接打开该目录；
- 命名：`YYYYMMDD_HHMMSS_<任务名>_<任务ID>.log`（任务名中的非法字符会被替换）；
- 内容：该次执行的完整记录（含 robocopy 原始输出、复制统计、退出码、校验结果），UTF-8 编码；
- 界面侧只做节流展示，**完整内容始终落盘**。

### 10.3 日志查看器

点卡片上的「日志」打开，显示文件**尾部约 32KB**：

- 标题 `任务「X」日志`，右侧显示日志文件路径；
- 底部说明：`完整日志已落盘（UTF-8），此处展示文件尾部约 32KB，滚动查看任务全程记录。`；
- 读取中 `正在读取日志…`；无内容 `日志为空`；失败 `日志读取失败：<原因>`；
- 当前版本**不提供**从界面导出日志的按钮，需要时请到日志目录复制文件。

## 11. 退出码对照表

robocopy 退出码 **0..7 视为成功**，**≥ 8 判为失败**（任务状态变为「失败」）。卡片上会显示如下解释：

| 退出码 | 界面文案 |
|---|---|
| 0 | 无文件需要复制（目标已是最新） |
| 1 | 成功复制了文件 |
| 2 | 目标端存在额外的文件/目录 |
| 3 | 成功复制，且目标端存在额外的文件/目录 |
| 4 | 存在不匹配（部分文件未能正确复制） |
| 5 | 存在不匹配，且已复制部分文件 |
| 6 | 存在不匹配，且目标端有额外文件 |
| 7 | 存在不匹配与额外文件，且已复制部分文件 |
| 8 | 复制失败：有文件无法复制 |
| 16 | 严重错误：robocopy 未能正常启动或参数非法 |
| 其他 ≥16 | 严重错误，请查看日志 |
| 其他 | 未知退出码 |
| 负数 | 进程被中止（多为被手动停止） |

## 13. 已知行为与限制

1. **不做持久化**：任务、运行设置、新任务默认参数都在内存中，关闭程序即丢失（见 [FAQ](./faq.md)）。
2. **文件列表与执行顺序不同**：列表按源路径字母序，执行按加入顺序先进先出。
3. **校验差异不单独成表**：只有汇总计数 + 日志文件里的前 10 条明细。
4. **`/R`、`/W` 无界面入口**：默认 `/R:1 /W:1`，只能通过日志/命令预览看到实际取值。
5. **界面版本号与安装包版本可能不一致**：设置里写「v2.0（Rust + Tauri 重构版）」，
   而打包配置的版本号是 `0.1.0`，以安装包信息为准。
6. **暂停能力**：只能「停止」，没有暂停/续传；恢复方式是用「重跑」重新开始
   （robocopy 自身会跳过目标端已是最新的文件，通常很快）。
7. **系统通知**：后端具备发送系统通知的能力，但当前界面在任务结束时只弹出应用内提示，
   不会弹 Windows 通知中心消息。
